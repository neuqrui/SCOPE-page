# Homepage button icons

- `github.svg`: GitHub's official black Invertocat from the [GitHub Brand Toolkit](https://brand.github.com/foundations/logo), used as a link to the project's GitHub repository.
- `huggingface.svg`: Hugging Face's logo from its [official Transformers.js examples repository](https://github.com/huggingface/transformers.js-examples/blob/main/attention-visualization/public/hf-logo.svg), used as a link to the Hugging Face collection.
- `chart.svg` and `paper.svg`: local interface icons for training curves and the forthcoming paper.
